# Data source

- Dataset: `CycPeptMPDB_Peptide_All.csv` (complete Peptide table)
- Original database: CycPeptMPDB, Cyclic Peptide Membrane Permeability Database
- Author-maintained repository: https://github.com/akiyamalab/cycpeptmp
- Original repository path: `data/CycPeptMPDB_Peptide_All.csv`
- Direct retrieval URL: https://raw.githubusercontent.com/akiyamalab/cycpeptmp/main/data/CycPeptMPDB_Peptide_All.csv
- File size: 15,842,300 bytes (approximately 15.1 MiB)
- Original paper DOI: 10.1021/acs.jcim.2c01573

The project downloaded the Peptide table directly from the paper authors' GitHub repository after the CycPeptMPDB official website timed out. The repository provides the database file; no third-party reformatted dataset was used. The raw CSV is preserved without edits.
